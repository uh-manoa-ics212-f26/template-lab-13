# Lab 13 Repository Guide

## Repository Setup Instructions

1. Navigate to the template.
2. Click the green **Use this template** button in the top right corner of the repository page.
3. Click "create a new repository".
4. Under **Owner**, select this organization (uh-manoa-ics212-f26).
5. Set the repository **Visibility** to **Private**.
6. Name your repository exactly like this: lab-13-your_uh_username

---

## Provided Files

Within the template you will have the following files that are currently empty.

* `week13_lab.c`: Your code for this lab.
* `written_response.txt`: Contains your written answers and explanations for each required problem section.
* `students.txt`: txt file for lab.
* `output.`: Text file showing the program output for Parts 1–4, including successful
operations and error-handling tests. NOTE: You can also upload screenshot instead.

---

## Submission

Please push all your lab work (all code and written answers) to your repository.
